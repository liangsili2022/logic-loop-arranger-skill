# Code of Conduct

This project follows the Contributor Covenant Code of Conduct, version 2.1.

## Our standard

Participants are expected to be respectful, direct, and constructive. Useful disagreement is welcome when it improves the project and stays focused on the work.

Unacceptable behavior includes harassment, personal attacks, sustained disruption, or publishing private information without permission.

## Enforcement

Maintainers may remove comments, close issues, or block participants when behavior harms the project or its contributors.

Report conduct concerns through the maintainer contact listed on the GitHub repository.
