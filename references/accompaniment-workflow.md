# Accompaniment Workflow

## Goal

Build Apple-Loops-based accompaniment that feels intentional, editable, and ready for a songwriter or producer to continue in Logic Pro.

## Preferred build order

1. Lock the brief.
2. Pick the loop family.
3. Find the rhythm anchor.
4. Find the harmonic bed.
5. Add bass support.
6. Add one or two signature textures.
7. Build section contrast.
8. Export and package.

## Loop selection heuristics

Prefer:
- loop names from the same family or pack
- harmonic sources with compatible mood
- drums that already imply the right pocket
- textures that support the lead space rather than crowding it

Avoid:
- over-stacking too many unrelated loops
- dense leads before the structure is working
- changing sound palette every section

## Section design

Use contrast, not randomness.

Common moves:
- Intro: keys or texture only
- Verse: rhythm enters, energy stays restrained
- Pre: add tension with motion or lift
- Hook: wider drums, brighter upper content, stronger bass commitment
- Breakdown: thin arrangement for reset
- Final hook: restore energy with one new detail
- Outro: reduce density and let emotion linger

## Export package

If the user wants a producer-ready handoff:
- render stereo WAV
- render aligned stems
- include a text arrangement guide
- include Logic import notes

## Quality checks

Always verify:
- duration
- sample rate
- channels
- loudness / peak sanity
- naming consistency

## Practical note on Logic

Logic is strong as a finishing environment, but weak as an external automation target.

So prefer:
- preparing files outside Logic
- importing cleanly
- using Logic for listening, editing, and finishing

Rather than:
- relying on deep GUI automation for core creation tasks
