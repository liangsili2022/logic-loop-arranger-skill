# Promotion Guide

This project should be promoted through useful examples and honest positioning, not spam or artificial popularity.

## Positioning

Short description:

> Logic Loop Arranger is a Codex skill for turning vague song direction into a producer-style accompaniment brief and Logic Pro handoff using Apple Loops.

Longer description:

> Logic Loop Arranger helps songwriters and producers move from references, mood words, and rough arrangement goals into a compact production brief, Apple Loops arrangement direction, and Logic-friendly delivery plan. It focuses on accompaniment, not lyrics, vocals, or brittle deep DAW automation.

## Good places to share

- music production communities when the post includes a concrete example
- Logic Pro user groups when discussing Apple Loops workflow
- AI music tooling discussions when the focus is agent workflow design
- Codex or agent-building communities when explaining skill structure
- personal project updates with a demo brief and repo link

## Avoid

- asking people to star without trying the project
- posting the same message across many communities
- implying the project can fully automate Logic Pro
- using private groups or mailing lists without permission
- hiding that the project is early-stage

## Example update

```text
I open-sourced Logic Loop Arranger, a small Codex skill for Logic Pro accompaniment workflows.

It helps turn vague direction like "late-night alt-R&B, sparse, room for topline" into a producer-style brief, Apple Loops arrangement plan, and Logic handoff notes.

It deliberately avoids overpromising full Logic Pro automation; the focus is creative intake, arrangement decisions, and clean handoff.
```

## Maintainer cadence

- Share only when there is a concrete update.
- Prefer demos, examples, and changelog notes over generic announcements.
- Track questions from users as GitHub issues when they reveal real workflow gaps.
